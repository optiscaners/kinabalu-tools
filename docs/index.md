# kinabalu-tools documentation

| Tool | Purpose |
|---|---|
| [can_send_trc](can_send_trc.md) | Replay CAN trace files (`.trc`) on PCAN hardware |
| [voice_to_can](voice_to_can.md) | Send a wave file as a stream of CAN frames |
| [raspi_can_relais](raspi_can_relais.md) | Switch CAN line and KL15/KL30 relays via Raspberry Pi GPIO |
| [lin_send_ldf](lin_send_ldf.md) | Send LIN frames from an LDF file on PEAK PLIN hardware |
| [firmware_duplicates](firmware_duplicates.md) | Report copied/modified source files across a firmware tree |
| [box_status](box_status.md) | Monitor the MQTT online status of boxes (htop-like view) |
| [task_monitor](task_monitor.md) | Decode task monitor dumps (watchdog state, log id call stack) |
| [analyze_emmc](analyze_emmc.md) | List all files of the Edge2 box file system (eMMC) with size via serial port |
| [analyze_serial_log](analyze_serial_log.md) | Message and match rates per second of the CAN / LIN counters in a box serial log |

See also [development.md](development.md) for setup, linting and project layout.
