# kinabalu-tools documentation

| Tool | Purpose |
|---|---|
| [can_send_trc](can_send_trc.md) | Replay CAN trace files (`.trc`) on PCAN hardware |
| [voice_to_can](voice_to_can.md) | Send a wave file as a stream of CAN frames |
| [firmware_duplicates](firmware_duplicates.md) | Report copied/modified source files across a firmware tree |
| [box_status](box_status.md) | Monitor the MQTT online status of boxes (htop-like view) |
